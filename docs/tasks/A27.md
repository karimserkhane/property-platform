# A27 — Interrupteur de collecte respecté par le script d'imagerie manuel

**Pourquoi** : l'interrupteur de collecte d'[A22](A22.md) doit pouvoir arrêter d'un coup
toute collecte qu'interdisent les conditions d'un site. [A25](A25.md) y a fait passer
les cinq chemins réseau des deux runtimes, mais a laissé une exception nommée :
`scripts/acquire_reem_imagery.py`, le script manuel qui recadre Reem dans les scènes
Sentinel-2. Il lit l'item STAC d'Earth Search, puis l'en-tête (`HEAD`) et des plages
(`GET` avec `Range`) du raster COG, par `urlopen`, sans consulter l'interrupteur.

**Dépendances** : A25 (point de passage `evidence/source_fetch.py` et test de garde
`apps/api/tests/test_network_entry_points.py`).

## Critères d'acceptation

- [x] Les trois appels réseau du script (item STAC dans `main`, `HEAD` et plages de
  `RangeReader`) passent par l'interrupteur avant de partir, redirections comprises.
- [x] Collecte appliquée et hôte revu comme interdit : le script refuse avant toute
  requête vers cet hôte ; collecte non appliquée : il collecte comme avant.
- [x] L'import du contrôle fonctionne, sans Django, dans l'environnement Rasterio
  isolé (`.cache/imagery-tools`) et dans l'image d'ingestion, où le script est copié ;
  la façon de faire est documentée.
- [x] Le script n'est plus une exception nommée du test de garde.
- [x] Les deux positions de l'interrupteur sont testées.
- [x] `checks-api` et `checks-ingestion` verts (`--no-deps`).
- [ ] CI verte sur la PR (lancée au passage en revue).

## Indications techniques

`apps/api/src/property_platform/modules/evidence/source_fetch.py` (`open_source`,
`collectable_url`) et `source_rights.py` (`collection_allowed`) n'importent que la
bibliothèque standard. Rasterio n'est présent que dans le venv isolé et dans l'image
d'ingestion : les tests du script vont dans `apps/ingestion/tests`.
