# F07 — Index des identifiants officiels de parcelles pour les imports de district

**Pourquoi** : Découpée de [F06](F06.md) le 28/10/2026. Le réimport direct de Madinat Al Riyad (exécution `exceptional-slug`) a échoué au délai de domaine de 3 600 s : chaque parcelle AD-SDI cherche son identifiant officiel dans son district (`sdi_import.py`, `identity_resolution.py`) par un parcours séquentiel de `real_estate.parcel` (367 074 lignes, environ 100 ms par recherche). Les 35 000 parcelles du district y ont passé 57 minutes. F06 ne peut pas réimporter les derniers districts sans cet index en base, donc il doit être fusionné et migré avant.

**Dépendances** : F05 (budgets d'un district AD-SDI).

## Critères d'acceptation

- [x] Index `parcel_official_plot` sur (`official_plot_id`, `municipality`, `district`) déclaré dans le modèle `Parcel` et créé par une migration additive (`catalog.0007`).
- [x] Contrôles Docker `checks-api`, `checks-ingestion`, `checks-web` et `pnpm docs:check` verts (`checks-web` par la CI GitHub, voir le journal).
- [x] Migration additive, applicable à la base partagée sans perte. Son application après fusion et le plan de la recherche d'identité (`EXPLAIN` utilise l'index) sont notés dans le journal de [F06](F06.md).
