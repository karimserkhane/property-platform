# A13 — Parcours navigateur en CI

**Pourquoi** : A05 livre `checks-e2e` en local, contre la base locale. La CI GitHub ne
les exécute pas encore : elle n'a ni API PostGIS ni données.

**Dépendances** : A05.

## Critères d'acceptation

- [ ] Jeu de données de démonstration reconstruit par migrations et pipelines (aucun dump
  versionné), suffisant pour chaque parcours : parcelles de Reem, quelques fiches dont
  une hiérarchie relue, une langue RTL.
- [ ] Job CI : PostGIS, API, jeu de démonstration, image `checks-e2e` ; traces et
  captures publiées comme artefacts en cas d'échec.
- [ ] Durée maîtrisée et aucun parcours marqué ignoré faute de données.

## Indications techniques

Réutiliser l'étape `e2e` du `Dockerfile` web et la configuration de
`apps/web/playwright.config.ts` ; voir [E2E.md](../engineering/E2E.md).
