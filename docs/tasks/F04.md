# F04 — Parcelles de l'émirat sur la carte et imports ADM et AAM

**Pourquoi** : Découpée de [F03](F03.md) le 27/10/2026. Le premier import (WRM, 40 752 parcelles) tient la charge en lecture sans territoire, mais le territoire `abu-dhabi` de l'explorateur ne réunit que les trois îles revues (`publication/coverage.py`) : les parcelles de l'émirat n'apparaissent pas sur la carte.

**Dépendances** : F03.

## Critères d'acceptation

- [x] Profil de couverture explicite pour les parcelles de l'émirat (espaces de noms `ad-sdi:generic-search:plots:<municipalité>:<district>` du registre revu), sans activer de collecte ni changer les identités des îles ; explorateur, tuiles, index par zone et recherche de parcelle le lisent.
- [ ] Imports réels ADM puis AAM par leurs déploiements manuels ; résultats, quarantaines et rapprochements avec les parcelles Onwani des îles notés.
- [ ] Mesures à l'échelle de l'émirat (temps de réponse, taille des tuiles, volume en base, recherche) comparées à celles de F03 dans `ENGINEERING_ROADMAP.md` ; index sur `code` ajouté seulement si la recherche le mesure nécessaire.

## Indications techniques

Mesures de départ : [ENGINEERING_ROADMAP.md](../engineering/ENGINEERING_ROADMAP.md), « Premier import de l'émirat : WRM ». ADM recoupe Al Reem, Saadiyat et Al Maryah : vérifier que la comparaison avec Onwani garde les conflits en quarantaine plutôt qu'en doublons.
