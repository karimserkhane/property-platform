# B14 — Sources autorisées pour les projets qui dépendent de sites interdits

**Pourquoi** : 103 projets sur 183 tirent leurs faits uniquement de sites qui interdisent la collecte. Avant tout tiers, l'interrupteur de publication les masquera ; sans sources autorisées, les essais [B13](B13.md) montreraient une plateforme à moitié vide ([audit](../engineering/AUDIT_STRUCTURE_20261108.md)).

**Dépendances** : A22.

## Critères d'acceptation

- [ ] Liste mesurée des projets et des champs concernés, par source interdite.
- [ ] Pour chacun, source autorisée trouvée (registre ADREC, documents officiels, licences obtenues par Karim) ou absence documentée.
- [ ] Collecteurs ajoutés selon les règles du dépôt (conditions lues, capture, audit), sans valeur inventée.
- [ ] Effet mesuré de l'interrupteur de publication avant et après, sur une base d'essai.
