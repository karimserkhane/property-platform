# A22 — Tout collecter et afficher, droits enregistrés et appliqués par interrupteur

**Pourquoi** : depuis [A19](A19.md), chaque source porte ses droits. Les collecteurs
sautaient les sites dont les conditions interdisent la collecte, et le site masquait ce
qu'elles ne permettent pas de publier, soit 90 fiches sur 183. Karim veut tout collecter
et tout voir dans son aperçu privé, avec le droit et la licence de chaque donnée
enregistrés. Il veut aussi pouvoir désactiver facilement, un jour, ce que les conditions
ne permettent pas.

**Dépendances** : A19.

## Décision du propriétaire

27/10, après la mise en service d'A19 : « la plateforme montre toutes les données, même
celles où c'est interdit, mais dans la base c'est marqué le droit et la licence ; comme
ça, si un jour je veux désactiver, c'est facile ». Karim laisse Claude choisir la mise en
œuvre pour la base, le code et la plateforme.

27/10, ensuite : « Active les pipelines aussi ». Claude lui avait rappelé que les
conditions de Property Finder, PSI, Aldar, Bayut, LinkedIn et Reddit interdisent la
collecte automatique ; Karim choisit de les collecter de nouveau.

Mise en œuvre retenue par Claude :
- **Les droits restent ce qu'ils sont** : le registre `source_rights.json`, sa copie en
  base et le champ `rights` de l'API décrivent toujours ce que permettent les
  conditions de chaque site.
- **Les appliquer est une décision séparée** : un interrupteur par droit (collecte,
  publication) dans `source_rights_enforcement.json`, daté, signé et motivé.
- **Aucun droit appliqué** pour l'instant : tous les pipelines collectent et tout est
  affiché. Chaque interrupteur, remis à `true`, arrête les collectes interdites ou
  masque ce qui n'est pas publiable, d'un coup et sans toucher aux données.

## Critères d'acceptation

- [x] `source_rights_enforcement.json` validé (deux droits, booléen, date, auteur,
  motif) ; ni la publication ni la collecte ne sont appliquées.
- [x] Publication non appliquée : toutes les lectures retrouvent leur comportement
  d'avant A19. Chaque source garde ses droits dans l'API.
- [x] Publication appliquée : tous les masquages d'A19 reviennent d'un coup. Les tests
  d'A19 l'appliquent explicitement.
- [x] Collecte non appliquée : les flows, `SourceHTTP`, les présentations et
  `project_bootstrap.py` atteignent de nouveau tous les sites. Appliquée, les refus
  d'A19 reviennent ; les deux positions sont testées.
- [x] Documentation : DATA_PROVENANCE, PROJECT_CATALOGUE, REPOSITORY.
- [ ] Contrôles CI verts sur la PR.

Hors périmètre :
- **[A20](A20.md)** : afficher licences et droits sur le site, et signaler les données
  montrées malgré les conditions.

## Indications techniques

Les fonctions `collection_allowed`, `facts_allowed`, `link_allowed` et
`withheld_capture_pattern` de `evidence/source_rights.py` lisent l'interrupteur.
Elles sont le seul passage des lecteurs listés dans
[DATA_PROVENANCE.md](../engineering/DATA_PROVENANCE.md#droits-de-chaque-source-a19).
Changer un interrupteur demande une PR, puis le redéploiement de l'API (publication) ou
de l'ingestion (collecte).
