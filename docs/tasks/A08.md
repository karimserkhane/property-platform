# A08 — Version de cache par famille de tables

**Pourquoi** : Toute écriture invalide tout le cache ; les collectes chaque minute le renouvellent sans cesse.

**Dépendances** : aucune.

## Critères d'acceptation

- [ ] Version par famille de tables à partir de `evidence.row_revision` (index adapté), sans perte de l'exactitude.
- [ ] Tests : une écriture sur une famille n'invalide pas les autres ; une exclusion invalide bien la lecture concernée.

## Indications techniques

Voir `api/read_cache.py` et la section cache de ENGINEERING_ROADMAP.
