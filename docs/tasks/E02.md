# E02 — Assistant IA qui cite ses preuves

**Pourquoi** : Répondre en langage naturel sans jamais affirmer sans preuve.

**Dépendances** : E01.

**Décision du propriétaire requise** : Valider le budget d'API et le fournisseur du modèle.

## Critères d'acceptation

- [ ] Réponses avec citations d'identifiants de preuve ; « je ne sais pas » sans preuve ; 16 langues.
- [ ] Jeu d'évaluation de 100 questions en CI : 0 affirmation non sourcée.
- [ ] Classement sémantique mesuré sur les affirmations publiées réelles (`evaluate_evidence_search`, modèle figé d'[E01](E01.md)) avant de choisir le mode de recherche par défaut ; téléchargement des poids soumis à Karim (reporté d'E01 le 28/10).

## Indications techniques

API Claude côté serveur, clé hors dépôt, coûts bornés.
