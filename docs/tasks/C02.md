# C02 — Simulateur d'échéancier et coût total

**Pourquoi** : L'effort de paiement réel dépend du plan du promoteur, des frais et du risque de livraison.

**Dépendances** : B02.

## Critères d'acceptation

- [ ] Plan de paiement sourcé, frais officiels cités, crédit facultatif ; frais inconnus affichés comme inconnus.
- [ ] Frise paiements / avancement déclaré.

## Indications techniques

Calculs purs testés, web.
