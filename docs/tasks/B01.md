Le registre consultable est l'annuaire public DARI (325 projets affichés) ; son interface exige un jeton (`401` sans jeton) et les conditions DARI interdisent explicitement robots, scrapers et republication automatisée. Une collecte ou l'affichage des valeurs exigerait une autorisation ADREC/ADRES que seul le propriétaire peut demander. Les conditions n'étant pas ambiguës sur la collecte automatique, aucune décision bloquante. Contrôles : `pnpm docs:check` ; contrôles Docker non lancés (documentation seule, aucun code modifié).
