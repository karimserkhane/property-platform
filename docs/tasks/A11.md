# A11 — Rejeu des anciens protocoles géographiques

Issue du premier contrôle réel A04 : les anciens champs `outFields` Onwani et les
anciennes requêtes Overpass diffèrent des protocoles actuels. Les octets existent,
mais un rejeu strict ne doit pas prétendre avoir exécuté une autre acquisition.

## Critères d'acceptation

Périmètre réduit le 23 octobre 2026 (voir le journal) : le contrôle réel, les anciennes
identités OSM et les écarts restants passent dans [A14](A14.md), car ils exigent ce code
déployé dans l'ingestion, donc fusionné.

- [x] Adaptateurs de rejeu explicites pour les versions historiques enregistrées
  (registre `evidence/replay_protocols.py`, requêtes recopiées depuis les commits cités),
  avec tests PostGIS sur les requêtes exactes et les géométries rejouées.
- [x] Aucune fusion par nom/proximité ni invention de champ non acquis : seule la
  requête d'origine est réémise ; une version non listée reste refusée.
- Déplacé vers [A14](A14.md) : conservation des anciennes identités, de leurs
  remplacements et des dates ; présentations et liens dépendant des anciennes identités
  OSM ; nouveau `rebuild-check` réel et contrôles sémantiques des écarts légitimes.
