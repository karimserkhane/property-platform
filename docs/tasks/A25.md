# A25 — Interrupteur de collecte respecté par tous les collecteurs

**Pourquoi** : l'interrupteur de collecte d'[A22](A22.md) doit pouvoir arrêter d'un coup
toute collecte qu'interdisent les conditions d'un site. Aujourd'hui il est coupé, et
tout est collecté comme Karim l'a décidé. Mais cinq chemins réseau ne le consultent pas
et continueraient le jour où il serait activé.

**Dépendances** : A22.

## Constat (29/10)

`SourceHTTP.fetch`, les flows de fiches, catalogues, références et présentations, et
`project_bootstrap.py` respectent l'interrupteur. Ne le consultent pas :
- ingestion : `collectors/accessibility.py` et `collectors/sentinel_windows.py`
  (`httpx` direct) ;
- API : `maps/map_sources.py` et `maps/onwani.py` (`urlopen`) ;
- API : `sources/research_import.py`. Le flow des références filtre ses lignes, mais un
  appel direct à `fetch_reference` ne passe pas par le contrôle.

## Critères d'acceptation

- [ ] Les cinq chemins passent par `collection_allowed` (ou par `SourceHTTP`) avant
  tout appel réseau, collecte appliquée ou non.
- [ ] Un test refuse tout nouvel appel réseau direct (`httpx`, `urlopen`, `requests`)
  hors des points de passage contrôlés.
- [ ] Les deux positions de l'interrupteur sont testées pour chaque chemin.
- [ ] Contrôles CI verts sur la PR.

## Indications techniques

`apps/ingestion/src/property_platform_ingestion/collectors/http.py` (`SourceHTTP`) ;
`evidence/source_rights.py` (`collection_allowed`).
