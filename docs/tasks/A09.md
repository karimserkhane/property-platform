# A09 — Découpage interne du module evidence

**Pourquoi** : 95 fichiers et 14 700 lignes dans un seul module.

**Dépendances** : aucune.

## Critères d'acceptation

- [ ] Sous-paquets `projects`, `maps`, `sources`, `history` sans changer l'application Django ni les migrations.
- [ ] Frontières vérifiées par Import Linter ; REPOSITORY.md à jour.

## Indications techniques

Déplacements mécaniques, réexports temporaires, aucun changement de comportement.

## Plan de découpage

Établi le 26/10 à partir des imports internes du module (voir [REPOSITORY.md](../engineering/REPOSITORY.md)). Direction : `rebuild` → `projects` → `maps` → `sources` → `history` → socle à la racine. Une étape par sous-paquet, chacune avec alias temporaires des anciens chemins ; suppression des alias en dernière étape.

- Socle (reste à la racine) : `models.py` et `*_models.py`, `apps.py`, `checks.py`, `runs.py`, `collection_profiles.py`, `media_storage.py`, fichiers JSON des registres, `management/`, `migrations/`.
- `history` (fait) : `history.py` → `history/journals.py`, `catalogue_history.py`, `pipeline_inventory.py`.
- `sources` (fait) : `adrec.py`, `adrec_import.py`, `abu_dhabi.py`, `context_import.py`, `research_sources.py`, `research_import.py`, `imagery_import.py`.
- `maps` (fait) : `onwani.py`, `map_sources.py`, `map_import.py`, `osm_api_protocol.py`, `osm_bootstrap.py`, `overture_protocol.py`, `overture_places.py`, `sdi_protocol.py`, `sdi_import.py`, `basemap_archive.py`, `identity_resolution.py`, `identity_repair.py`, `accessibility.py`, `services.py` (importe `identity_resolution`). `failed_acquisitions.py` importe aussi `project_discovery` et `project_protocol` : il rejoindra `rebuild` avec `orchestration.py`, son seul appelant.
- `projects` (fait) : `project_*.py`, `property_protocol.py`, `property_import.py`, `queries.py` (cycle avec `project_queries.py`), `verification_sheet.py`, `delivery_history.py`, `activity_import.py`, `activity_sheet.py`.
- `rebuild` (fait) : `rebuild_archive.py`, `rebuild_published.py`, `replay_protocols.py`, `demo_package.py`, `orchestration.py`, `failed_acquisitions.py`.
