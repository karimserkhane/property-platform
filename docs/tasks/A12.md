# A12 — Reconstituer les versions historiques des interprétations

Issue du contrôle A04 : les captures recréent les 183 projets, mais les importateurs
actuels dédupliquent ou interprètent autrement des versions qui avaient été ingérées
avec d'anciens registres/extracteurs. Rejouer les octets avec le code actuel ne suffit
pas à prouver la reproduction de toutes les anciennes interprétations.

## Critères d'acceptation

- [ ] Identité durable de la version de registre et d'extracteur utilisée pour chaque
  interprétation ; conserver les anciennes assertions et leurs preuves.
- [ ] Rejeu des versions de fiches/catalogues, typologies, équipements et références
  médias ; tests des champs présents uniquement dans une ancienne version.
- [ ] Vérifier les valeurs publiées et leur provenance, en plus des comptes par table ;
  justifier toute différence légitime sans recopier le catalogue attendu.
- [ ] `rebuild-check` couvre ces versions et ne signale plus de perte inexpliquée.
