# A20 — Licences et attributions affichées sur le site

**Pourquoi** : depuis [A19](A19.md), l'API donne les droits de chaque source d'une fiche
(`rights` : licence, conditions, niveau de publication, attribution, date de revue). Le
site ne les montre pas encore. Les licences ouvertes (ODbL, CC BY, CDLA, Copernicus)
exigent une attribution visible, et un visiteur doit savoir ce qui est réutilisable.

**Dépendances** : A19.

## Critères d'acceptation

- [x] Chaque preuve dépliable d'une fiche affiche la licence de sa source (ou « conditions
  non relues ») et le lien vers ses conditions.
- [x] Tant que la publication n'est pas appliquée ([A22](A22.md)), une donnée dont la
  source ne permet que le lien (`link`) ou rien (`none`) est signalée comme telle.
- [x] Une page « Sources et licences » liste les sources publiées, leur licence et leur
  attribution, depuis le registre (nouvelle lecture d'API si nécessaire).
- [x] Attributions des cartes alignées sur le registre (OpenStreetMap, OpenFreeMap,
  ESA WorldCover, Copernicus, Overture) au lieu de textes codés en dur.
- [x] Libellés dans toutes les langues activées, RTL compris
  ([INTERNATIONALIZATION.md](../engineering/INTERNATIONALIZATION.md)) ; parcours e2e mis à
  jour.

## Indications techniques

`apps/api/src/property_platform/modules/evidence/source_rights.py` (`public_rights`),
`api/projects.py` (`SourceRightsResponse`), `apps/web/src/features/projects/`.
