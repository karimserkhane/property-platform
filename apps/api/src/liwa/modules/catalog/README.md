# Catalogue

Possède l'identité des territoires, parcelles, bâtiments et logements, ainsi que leurs relations acceptées. Les modèles seront définis avec le dossier pilote ; aucun modèle générique JSON ne remplace ces invariants.

N'importe pas les modules evidence/publication ni la couche HTTP. Les autres modules utilisent ses services de mutation et ses fonctions de lecture explicites.
