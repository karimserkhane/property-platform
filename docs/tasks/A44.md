# A44 — Files Prefect qui ne tournent plus à vide

**Pourquoi** : Quatre files passent toutes les deux minutes, soit 2 880 courses par jour. `walking-areas` : 8 430 exécutions en 14 jours et zéro zone enregistrée. Chaque passage écrit une ligne d'exécution et son journal, et la base Prefect atteint 1,5 Go ([audit](../engineering/AUDIT_STRUCTURE_20261108.md)).

**Dépendances** : A26.

## Critères d'acceptation

- [x] Une file vide n'écrit ni exécution ni journal ; test à l'appui.
- [x] Le travail demandé reste pris en charge dans le même délai qu'aujourd'hui, ou le délai retenu est justifié.
- [x] L'historique Prefect a une durée de conservation documentée.
- [ ] Le gain est mesuré après déploiement : courses par jour, lignes de journal par semaine.
