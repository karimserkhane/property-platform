# A43 — Déploiement scripté, version étiquetée et retour arrière

**Pourquoi** : La mise à jour de la prévisualisation est une suite de commandes à la main ([AGENT_WORKFLOW.md](../engineering/AGENT_WORKFLOW.md), section 7), sans version étiquetée ni retour arrière ([audit](../engineering/AUDIT_STRUCTURE_20261108.md)).

**Dépendances** : A42.

## Critères d'acceptation

- [x] Un script vérifie que `main` est à jour, conserve les images en place, construit, recrée dans le bon ordre (`remote-preview` après le site), applique les migrations et vérifie la santé.
- [x] Il attend la fin des courses Prefect longues avant de recréer l'ingestion, ou annonce ce qu'il interrompt.
- [x] Chaque déploiement porte une étiquette Git datée et une note de version.
- [ ] Une commande revient à la version précédente ; un essai réel est noté, avec l'accord de Karim. (**Commande écrite et testée à blanc ; essai réel après fusion, avec l'accord de Karim.**)
