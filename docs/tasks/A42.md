# A42 — Cycle de mises à jour de toutes les applications et de tous les outils

**Pourquoi** : Dependabot propose ce qu'il sait lire. Les versions qu'il exclut (Playwright, Valhalla, modèle d'embeddings, versions majeures de PostgreSQL), celles qui vivent à plusieurs endroits (`uv`, Node, pnpm) et les outils du PC (Node, Docker Desktop, Git, GitHub CLI) n'ont aucun rappel : le PC tourne encore sur un Node à faille exploitée ([audit](../engineering/AUDIT_STRUCTURE_20261108.md)).

**Dépendances** : aucune.

## Critères d'acceptation

- [ ] Un registre liste chaque composant, où sa version est figée, où lire la dernière version publiée et qui le met à jour.
- [ ] Une commande compare les versions figées aux dernières publiées et applique le délai de 7 jours ; une option ajoute les outils du PC.
- [ ] Un workflow hebdomadaire tient à jour une issue unique avec ce rapport.
- [ ] `docs/engineering/RELEASE_CYCLE.md` décrit le rythme : chaque semaine, chaque mois, versions majeures, qui décide, comment revenir en arrière.
