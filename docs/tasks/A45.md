# A45 — Rôles PostgreSQL séparés et base d'essai par agent

**Pourquoi** : L'API, l'ingestion et les agents utilisent la même identité, super-utilisateur. Un agent peut écrire dans la base partagée par erreur, et aucun ne peut essayer une donnée réelle sans risque ([audit](../engineering/AUDIT_STRUCTURE_20261108.md)).

**Dépendances** : aucune.

## Critères d'acceptation

- [x] Un rôle en lecture seule pour les agents, un rôle applicatif sans droit super-utilisateur, créés par une procédure rejouable sans SQL manuel sur la base partagée.
- [x] Une commande crée puis supprime une base d'essai par agent, avec un contrôle de la place disque avant.
- [ ] Les sauvegardes, `restore-check` et `rebuild-check` restent verts.
- [x] Le changement d'identité de l'API et de l'ingestion est essayé dans un environnement à part avant d'être proposé.
